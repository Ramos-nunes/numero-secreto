# 🎯 Jogo do Número Secreto

Um jogo interativo desenvolvido em JavaScript, HTML e CSS, criado durante os cursos do programa **Oracle Next Education (ONE)** em parceria com a **Alura**.

O objetivo do jogo é descobrir o número secreto gerado aleatoriamente pelo sistema entre 1 e 10, recebendo dicas se o número alvo é maior ou menor.

---

## 🚀 Funcionalidades

- **Sorteio Dinâmico:** Geração de números aleatórios sem repetição imediata até que todos os números do intervalo sejam sorteados.
- **Contador de Tentativas:** Cálculo inteligente do número de tentativas necessárias até o acerto.
- **Síntese de Voz Integrada (Web Speech API):** O jogo fala as instruções e o resultado em Português nativamente através do navegador, sem dependências de chaves externas de API.
- **Interface Responsiva:** Estilização com gradientes e suporte para diferentes tamanhos de ecrã.
- **Reinício de Jogo:** Botão de novo jogo reativado automaticamente após a vitória.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica da página.
- **CSS3:** Estilização visual, layout flexível e gradientes.
- **JavaScript (ES6):** Manipulação de elementos do DOM, regras de negócio e integração com a `window.speechSynthesis`.
